# 女王争宠棋 · 主持版 V2

网址：https://duggeechen.github.io/queen-court-play/

1—6名参与者，始终由主持人控制。参与者可点摇骰，也可由主持代摇；其他判定由主持确认。默认按昵称排列顺序开局，支持可选骰子抽签。

手机界面集中呈现位置、当前玩家、下一位和大骰子。普通掷骰自动走棋；重掷资格才显示选择；点数和卡片特写，纯数值卡自动结算，护盾仍确认。所有角色任务可以换卡或跳过，暂停优先。

2人挑战+2/0；3—6人+2/+1，其余0；支持并列、同批完赛勋章/骰子排序。单人不触发对手PK与共同挑战。

旧三人存档保持可继续，使用同一浏览器存档键。网页没有登录或云存档；换设备不会同步。卡片默认编辑不影响进行中的配置快照。

运行无需依赖，可用静态HTTP服务器。验证：Node.js 22以上运行 `npm test`。28组引擎测试，包含100个三人种子及30个1—6人完整棋局。
